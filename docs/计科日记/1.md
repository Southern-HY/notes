# 1

今天下雨了。淅淅沥沥的微雨，西安很少见到这样的天气。

现在是凌晨三点，雨还在下。我躺在床上，处于一种半睡半醒的状态，窗外从不间断的雨声和我做的梦融合到了一起。

橘色身体、长者四条腿的怪物是什么？它有着四条细细的腿，粗壮短小的手臂，分得很开的黑色小眼睛，像某种火星生物。我今天看到了它很多回。它是一个新朋友，捉摸不定，但我并不讨厌它。它总是张开短小的手臂，露出宽阔的胸膛，要用最温暖的怀抱接纳我。不过在那之前，我要弄清它的底细。

我需要找一个地方，不是这个冷雨中的温暖宿舍，不是这张硬板床。我在这里手脚动弹不得。我要找的是一个真正能容纳我、赋予我真正自由的地方。

这个地方是我从高三读的一篇语文阅读题上找到的。故事的情节大概是，主角是工业革命时的一名小孩，住在大城市里，家人们都因为空气污染染上肺癌，住进了郊外山坡上的疗养院。主角最终也去了疗养院，见到了其他的病人们。眼下，我找到了这个地方，同病人们一样换上了白色的衣服，走在微风吹拂的草坡上，缓慢接近那高地上的疗养院那古朴的砖房。

我跟放风回来的病人们一道。走在草地上，他们什么也没说。都是从城市里侥幸逃出来的人，能够呼吸新鲜空气，不必说什么。沉默一直延续到很久。

我想起了我曾经编的一个有一点克苏鲁式的故事：一位从远方星空中来的神明想要控制地球，于是选中了一位计算机学生作为自己的代理人，控制了他（她？）在正反两个世界中不断作恶。最终，主角在新旧朋友们的帮助下，掌握了控制能量的方法，将入侵者囚禁住，自己则进入了“雨雾世界”。在雨雾世界，主角为自己建立了一所疗养院，并在其中寻找着逃出的方法。

我现在就是那个故事的主角，住进了雨雾中的疗养院。我搬了一张扶手椅，坐在疗养院中庭的大窗户旁，静静地看着外面被青色雾气笼罩着的、不确定的世界。在这里，我能够让思绪轻轻地触碰过去和未来，体会一切事情的发生，暂短地脱离此时此刻。

我的旧朋友们，我有多久没见到他们了？前几天是中秋节，晚上我们一起拉了个视频会议，不过讨论的东西非常有限。我们就像一群小狗，见到对方就兴奋地摇尾巴。我想起曾经在高铁站旁的乡村小路上看到的情景：一只成年的黄狗后面跟着几只小黄狗，正慢慢溜达进两旁覆盖芭蕉叶的小路上。我听说，它们的快乐就是无忧无虑地自由乱跑。不过，想到它们没办法感受 IT 行业的魅力，我还是不禁感到有点可惜。

我曾迫切地希望，所谓“平行世界”是真实存在的。我需要一个理由，为了某些更好的选择牺牲掉某些次好的选择，尽管我两者都不愿放弃；有时也是为我一时胆怯的选择提供心理安慰：也许在其它某个地方，在我们也许永远到不了的地方，一切都照常，只不过梦想成了现实。

也许一切曾会不一样？

我想起了之前看到的一篇论文里的 beam-search 示意图，像分叉的树枝。可惜我们无情地把多少有趣而潜力无限的分支都剪掉了，只剩下现存的“过去”，被紧紧地收敛成一条。未来这将继续发生。

真的非常可惜。

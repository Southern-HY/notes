# 再下一代交互

脑机接口的到来，又会改变许多东西。（如果有那一天的话）

### 神经化互联网

有时我躺在床上时，会闭上眼幻想大脑里有一个浏览器窗口——我不需要用眼睛就能看到，而且无比具象和清晰。我也无需动手，仅凭“精神的触手”就能按动 Web App 上的各种元素。我于是便意识到，我已经想摆脱屏幕很久了。

互联网神经化的第一步，是将传统的操作模式照搬到神经连接中。以前的前端、后端、Web App，各种技术栈都还在，交互模式也无需变化，只不过没有了鼠标、键盘和显示器。相反，人们能够直接用神经连接取代传统的任何操作。

第二步，是开发出神经相关的特色内容。例如，假如我们打开一个在线花店应用，从服务器传来的不仅有花的售价、图像、评价等数据，还包括一些“神经内容”：比如花的香气、触感，还有隐隐的愉快感。这些“感觉”都由神经终端解码，并利用神经连接直接发送给我们的大脑。

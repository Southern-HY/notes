# 多巴胺计划

怎样能够让自己过得更加快乐？

我很早就以前就发现，我的快乐与否，有相当大一部分取决于大脑的状态，而不仅仅来源于外物的变化。

大脑的状态，需要内生地去调控。于是我就需要自己去想些东西。想些什么呢？

### 故事

从前我以为，一颗情绪稳定、保持常态、任何时候都能保持绝对理性和敏锐探知的大脑，是通向幸福的关键。但我现在发现不对。这样只会让自己变得木讷。

我应该敞开胸怀，让更多的情绪涌进来。

我需要更多故事。如果自己的故事不够，可以拿别人的来凑。多看点电影或小说也许会有帮助。

我很幸运。我脑袋里有故事，我可以画出来，或是写成文字及音乐。

我还要多参与人际交往，多认识新的朋友，多开发自己新的故事。

### 做事

“做有用的事”，这是能让我进入好的状态的最有效以及根本方法。我可以不惜骗自己，相信自己当前做的事是有意义的。

除此之外，所有的娱乐之物，如喝饮料、听音乐、打游戏或刷视频，都只是辅助，能够短时间地刺激多巴胺的释放，让好的状态多保持一会。

然而，娱乐要适度；不然会适得其反，使自己失去好的状态。需要对自己的状态保持觉察，在合适的时候退出。

### 夜晚

不要去探知夜晚。上了床就好好睡觉，保持夜晚的神秘，相信明天和今天没有关系。

### 音乐

音乐很危险，它能很轻易地左右大脑的状态。

听得太多不好；听得太杂乱不好；听的音乐与大脑目前状态趋势相抵触也不好。

更多时候，我会选择去听适度的音乐。有时，只听一首会最合适。

### 集中70%的注意力。

不必强迫自己一直保持专注。

如果在电脑前待累了，别努力去找事做。可以出去放放松。

# Windows 字体替换记录

Windows 上的字体显示一直都有点问题。尤其是在我的 2K 显示器上，像微软雅黑、Consolas 这样的系统字体在默认的阅读大小下会有比较大的锯齿，看得很不舒服。

之前我用的是 MacType 这个软件。不过后来发现，MacType 下的字会有点糊，并且它需要独立加载。

鉴于大多数时候引发不满的都是微软雅黑，于是我最终卸掉了 MacType，然后采用了【替换微软雅黑】这个方法。

Noble Scarlet 是一款字体，微软曾经开发来作为微软雅黑的改进版，不过后来砍掉了。我从 [https://github.com/jlxd/Noble-Scarlet-mod](https://github.com/jlxd/Noble-Scarlet-mod) 下到了 Noble Scarlet 的字体文件。

随后， shift + 重启 进入高级启动选项，打开命令行，将字体拷贝到 C:\windows\fonts 下。

重启后，系统自带的微软雅黑字体就已经被替换了。小的文字也显示得很漂亮。

---

备注：

1. 如果想要修改成其它字体，可以使用 [https://github.com/Tatsu-syo/noMeiryoUI](https://github.com/Tatsu-syo/noMeiryoUI) 这个软件。似乎会将所有用到系统字体（比如微软雅黑）的地方都一起修改。

2. 高级启动选项中，如果要进命令行，可能会需要输入 Bitlocker 恢复密钥。可以在 aka.ms/myrecoverykey 中查看。

3. 这种方法无法使别的字体显示得更好，比如 Consolas。（除非替换掉 Consolas 的字体文件）

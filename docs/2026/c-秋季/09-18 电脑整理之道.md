# 电脑整理之道

### 符合系统意图的文件存储

Windows 的用户文件夹下有图片、文档、音乐、视频等文件夹，要善于运用它们，妥善归类整理自己的文件。常用的文件夹（比如 Coding）可以加入文件管理器的侧边快捷方式中。

我常用的固定文件夹有：

- 用户/图片，存储收藏的图片、壁纸、屏幕截图等
- 用户/音乐，里面有我自己下载的 mp3 以及从别人那里拷来的音乐
- 用户/桌面/Coding，按语言存放所有代码
- 用户/桌面/2D（以及3D），存放 2D 和 3D 设计文件
- 用户/笔记本：所有的生活和学习笔记，以 Markdown 格式存储
- 用户/文档/书籍，所有书籍的 pdf 版本
- 用户/文档/暂时不用，所有的个人档案、记录、安装包、杂项文件

### 桌面“一件事”

桌面上去除所有的程序快捷方式，以及文件，只保留文件夹。每个文件夹对应“一件事”（比如实习 / 社会实践），入口区分开。桌面只能保留工作进行中产生的临时文件。

每次离开电脑时，或去做另一项任务时，这些桌面上的临时文件都要被清除。删掉或是放到文件夹里。

### 总是保持回收站清空

这纯粹是为了我的强迫症着想。我经常害怕自己误删了什么东西，于是一次次去翻回收站。

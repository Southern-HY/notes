# 下一代交互

*8/11*

### 可变注意力软件

有了AI的辅助，任何人都能够开发软件实现自己想要的功能。我们也许会迎来一个软件数量爆炸式增长的年代。

然而，软件的数量增加，但我们的注意力却始终有限。我们实在不可能把每一个软件的所有功能都掌握清楚；只能根据自己实际的需求，取每个软件中的一小部分来用。我希望，未来人们能够实现软件的**可变注意力**。

这可以是软件自己的UI功能：只将我们需要的功能，在需要的时候主动地呈现，而在其它时候保持低调；这也可以由我们自己的AI Agent来实现，作为我们和软件之间的代理，避免我们直接和所有的细节功能打交道。

### 拟人化服务

即时是“数字原生”的人，终究也会厌倦于与一个又一个冰冷的界面打交道。也许有一天，人们会希望能够重新获得当初与真人交往的那种亲近感和活力。AI进步后，**拟人化服务**或许会更加受到大众的喜爱。

想象你登录一家IT硬件公司的网站，你面对的不再是各种业务介绍、购买指引等争相吸引你注意的板块，而是只有一位站在柜台后面的数字服务员，真切地询问你想获得什么样的帮助。
